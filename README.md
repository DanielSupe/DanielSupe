## Sobre mí

Desarrollador Full Stack con **3 años de experiencia** construyendo aplicaciones web y móviles **en producción** para clientes de Estados Unidos, con foco en plataformas logísticas B2B: módulos de gestión de envíos, facturación y transacciones.

Trabajo el stack completo en JavaScript y TypeScript — React.js y Next.js al frente, Node.js y Express detrás, APIs REST y GraphQL sobre SQL Server y PostgreSQL. Un paso reciente por Business Intelligence (ETL, T-SQL y Power BI para la operación de Avianca) me dejó algo que uso a diario: leer los datos antes de escribir la query.
